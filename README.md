# bug-tracker
This project is a browser-based bug tracking application built with HTML , CSS, and JavaScript. It was created to strengthen my JavaScript skills while applying concepts from my software testing and quality assurance experience.

A web application that allows users to log, track, and manage software bugs.

## Features
- Create bug reports with a title and description
- Assign Low, Medium, or High priority levels
- Set bug status to Open, In Progress, or Closed
- Filter bugs by status
- Delete bug reports
- Form validation to prevent incomplete reports
- Dynamically render and update bug reports without refreshing the page
- Responsive user interface

## Technologies
- HTML - application structure  
- CSS - styling and responsive layout
- JavaScript - application logic and interactivity

## JavaScript Concepts Practiced
- DOM manipulation
- Event listeners and event handling
- Form validation
- Arrays and objects
- Dynamic HTML rendering
